# Root Directory

Entry point for the NixOS configuration. All system-level and home-manager configuration originates here.

---

## Files

### configuration.nix
Main NixOS system configuration, evaluated at `nixos-rebuild switch`. Covers:
- Hardware: Intel CPU + NVIDIA GPU hybrid graphics (PRIME offload), kernel `6.12`, BBR network congestion control
- Boot: Plymouth boot animation (`simple` theme), quiet boot params
- Services: PipeWire audio, Bluetooth, CUPS printing, OpenSSH, Flatpak, ratbagd (mouse config)
- Desktop: Hyprland + GNOME/GDM as display manager
- Localization: French keyboard, `Europe/Paris` timezone, `fr_FR.UTF-8` locale
- Security: passwordless sudo for the main user
- Fonts: Noto, Liberation, MesloLG Nerd Font, JetBrains Mono Nerd Font, UdevGothic NF
- Nix: flakes enabled, 14-day garbage collection
- Imports `home.nix` via `<home-manager/nixos>`

### home.nix
Home Manager configuration for the main user. Evaluated as part of `nixos-rebuild switch`.
- Dynamically imports every subdirectory of `config/programs/` as a module
- Imports `config/sessions/hyprland/default.nix`
- Declares user packages (tools, development, multimedia, gaming, productivity)
- Configures GTK/Qt theming (adw-gtk3-dark, Papirus-Dark icons)
- Configures cursor (ArcMidnight)
- Manages font files from `config/fonts/`
- Sets up dconf (dark mode, GTK theme), XDG portals, EasyEffects service

### variables.nix
Single source of truth for the username and hostname. Imported in both `configuration.nix` and `home.nix`.
```nix
{
  username = "thron";
  hostname = "nixosbtw";
}
```

### hardware-configuration.nix
Auto-generated by `nixos-generate-config`. Declares kernel modules, filesystems, and CPU microcode settings specific to the machine. **Do not edit manually** — regenerate with `nixos-generate-config` if hardware changes.
