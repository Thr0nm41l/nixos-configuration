# config/sessions/hyprland/scripts/quickshell/

The Quickshell-based widget system. All UI is written in QML and rendered by `quickshell`. Scripts in subdirectories support the widgets with data fetching, event watching, and hardware control.

All files are deployed to `~/.config/hypr/scripts/quickshell/` via symlink.

---

## Core QML files (root level)

### Main.qml
Master overlay window. A transparent full-screen `PanelWindow` that:
- Holds all popup widgets (battery, calendar, music, etc.)
- Receives open/close commands by polling `/tmp/qs_active_widget` (written by `qs_manager.sh`)
- Applies a region mask so the top bar area passes mouse events through

### TopBar.qml
Top system status bar. Spawns one panel per monitor. Contains:
- Workspace switcher (reads `/tmp/qs_workspaces.json`)
- System tray
- Status indicators (clock, battery, network, volume)
- Help icon (toggles guide widget)

### Lock.qml
Lock screen. Launched directly by `lock.sh` as a separate Quickshell process (not part of the main overlay).

### MatugenColors.qml
Shared color palette singleton. Reads `/tmp/qs_colors.json` (generated by matugen) and exposes the 30 Catppuccin color names as QML properties. Imported by every widget that needs theme colors.

### Scaler.qml
Responsive scaling helper. Provides a `s(value)` function that scales pixel values proportionally to screen size. All widgets use `root.s(N)` instead of hardcoded pixel sizes.

### ScreenshotOverlay.qml
Interactive region selection overlay. Used by `screenshot.sh --record` to let the user draw a capture rectangle on screen.

## Widget popups

Each widget is a QML file that displays as a floating overlay. Opened/closed via `qs_manager.sh toggle <name>`.

### battery/BatteryPopup.qml
Shows battery percentage, charge status, and power mode selector (via `power-profiles-daemon`).

### calendar/CalendarPopup.qml
Monthly calendar view. Includes:
- Date navigation
- Diary button — calls `diary_manager.sh` to open today's Obsidian note
- Weather display — calls `weather.sh`
- Optional schedule module (disabled if `schedule_manager.sh` is not present)

### focustime/FocusTimePopup.qml
Focus/productivity timer. Displays time-per-application statistics fetched from the SQLite database maintained by `focus_daemon.py`.

### guide/GuidePopup.qml
User guide and settings panel. Contains:
- Keybind reference (tab 0: system overview)
- Settings editor (tab 1: UI scale, language, wallpaper directory, guide autostart)
- Resource links (tab 2)
- Module list (tab 3)
- Attribution link to the original rice repo (`ilyamiro/nixos-configuration`)

Settings are saved to `~/.config/hypr/settings.json` and applied live by `settings_watcher.sh`.

### monitors/MonitorPopup.qml
Display configuration widget. Allows changing resolution, refresh rate, and monitor arrangement without editing `monitors.nix`.

### music/MusicPopup.qml
MPRIS music player widget. Shows current track, artist, album art, and playback controls. Calls `music_info.sh` and `player_control.sh`.

### network/NetworkPopup.qml
Network management panel:
- Wi-Fi: lists available networks, connects/disconnects (via `wifi_panel_logic.sh`)
- Bluetooth: scans for devices, pairs/connects (via `bluetooth_panel_logic.sh`)

### notifications/NotificationPopups.qml
Desktop notification display. Receives notifications from swaync and renders them as styled popups in a corner of the screen.

### volume/VolumePopup.qml
Full audio mixer:
- Output device selector
- Input (microphone) device selector
- Per-application volume sliders
All data from `get_audio_state.py`, control via `audio_control.sh`.

### wallpaper/WallpaperPicker.qml
Wallpaper manager:
- Browses local wallpaper directory (thumbnails pre-generated by `qs_manager.sh`)
- DuckDuckGo image search (calls `ddg_search.sh` / `get_ddg_links.py`)
- Sets wallpaper via `swww img` and triggers `matugen_reload.sh` to regenerate colors

### stewart/stewart.qml
Custom project-specific widget (Stewart project workspace launcher).

## calendar/

Supporting scripts for `CalendarPopup.qml`.

### diary_manager.sh
Creates and opens a daily Obsidian note.
- Vault path from `$OBSIDIAN_VAULT_DIR` (default: `$HOME/Documents/Obsidian`)
- Vault name from `$OBSIDIAN_VAULT_NAME` (default: `Obsidian`)
- Creates `Diary/<year>/<day>.<month>.md` and updates `Diary/Contents.md` index
- Opens the note via `obsidian://open?vault=...` URI

See `documentation/howto/obsidian-diary.md` for user setup instructions.

### weather.sh
Fetches current weather data (temperature, conditions) for display in the calendar widget. Uses a public weather API.

## focustime/

### focus_daemon.py
**Application usage tracker.** Started at session launch via `autostart.nix`.

- Listens to Hyprland IPC socket for `activewindow` events
- Tracks time spent in each window class/title combination
- Writes to a SQLite database at `~/.local/share/focustime/focus.db`
- Records per-day, per-week, per-month breakdowns

### get_stats.py
Queries the SQLite database and returns JSON statistics for display in `FocusTimePopup.qml`. Accepts a time range argument (day / week / month).

## music/

Supporting scripts for `MusicPopup.qml`.

### music_info.sh
Fetches current track metadata via `playerctl` (title, artist, album, album art URL). Returns JSON.

### player_control.sh
Wrapper around `playerctl` commands: play, pause, next, previous, seek.

### equalizer.sh
Controls EasyEffects presets via its D-Bus interface. Called from the music widget's equalizer section.

## network/

### wifi_panel_logic.sh
Wi-Fi management via `nmcli`:
- Scans for available networks
- Returns SSID list with signal strength and security type
- Connects to / disconnects from networks

### bluetooth_panel_logic.sh
Bluetooth management via `bluetoothctl`:
- Scans for nearby devices
- Returns device list (name, MAC, connected/paired status)
- Pairs, connects, and disconnects devices

## volume/

### audio_control.sh
PipeWire audio control via `pamixer` and `pactl`:
- Set/get volume for sinks and sources
- Mute/unmute
- Set default sink/source
- Set per-application volume (sink inputs)

### get_audio_state.py
Queries PipeWire's JSON API and returns a complete audio state snapshot:
- List of output sinks with volumes and mute states
- List of input sources
- List of active applications (sink inputs) with volumes
- Current default sink/source

## wallpaper/

### matugen_reload.sh
Triggers a full color refresh after a wallpaper change:
1. Runs `matugen image <wallpaper_path>` → generates all template outputs (see `matugen/config.toml`)
2. Sends a reload signal to Quickshell to pick up the new `/tmp/qs_colors.json`
3. Reloads kitty colors from `/tmp/kitty-matugen-colors.conf`

### ddg_search.sh
Downloads wallpaper thumbnails from a DuckDuckGo image search:
- Calls `get_ddg_links.py` for image URLs
- Downloads thumbnails, converts WEBP to JPG with ImageMagick
- Respects pause/stop signals written to `/tmp/qs_ddg_control` by the wallpaper widget
- Validates images before saving to prevent broken previews

### get_ddg_links.py
DuckDuckGo image search scraper:
- Fetches VQD token from the DDG search page
- Scrapes image result JSON for thumbnail + full-resolution URL pairs
- Returns a list of `{"thumbnail": ..., "image": ...}` objects

### debug_pipelines.sh
Developer utility for debugging the wallpaper thumbnail generation pipeline. Not used in normal operation.

## watchers/

Watcher scripts follow a consistent two-script pattern used by Quickshell for reactive data:

- **`*_fetch.sh`** — Returns the current state immediately as JSON (called once on widget open)
- **`*_wait.sh`** — Blocks until the state changes, then exits (Quickshell re-runs it in a loop to get live updates)

| Watcher pair | Data source | What it tracks |
|---|---|---|
| `audio_fetch/wait` | `get_audio_state.py` + PipeWire socket | Volume, mute, default device |
| `battery_fetch/wait` | `acpi` | Battery %, charging state |
| `bt_fetch/wait` | `bluetoothctl` | Bluetooth device list |
| `kb_fetch/wait` | `hyprctl` | Current keyboard layout |
| `network_fetch/wait` | `nmcli` | Wi-Fi network list and connection state |
| `workspaces.sh` | Hyprland IPC socket | Active workspace, open windows per workspace |

### workspaces.sh
Workspace state emitter (standalone, not a fetch/wait pair):
- Opens a persistent connection to Hyprland's IPC event socket via `socat`
- Debounces rapid workspace-change events with a 50 ms grace period (prevents CPU thrashing on fast workspace switching)
- Writes current workspace state as JSON to `/tmp/qs_workspaces.json` after each debounced event
- Handles zombie process cleanup on exit
