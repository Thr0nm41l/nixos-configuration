# config/programs/

Each subdirectory is a Home Manager module. `home.nix` auto-imports every subdirectory here, so adding a new folder with a `default.nix` is enough to activate it — no manual import needed.

The predominant deployment pattern is an **out-of-store symlink**: the Nix module points `~/.config/<app>` at `/etc/nixos/config/programs/<app>`, so the config files can be edited live without rebuilding.

---

## cava/

Audio visualizer (terminal bars).

### default.nix
Creates a wrapper script that merges the static base config with matugen-generated colors at launch time, then symlinks the result into `~/.config/cava/`.

### config
Base CAVA configuration (static part). Colors are injected by matugen at runtime and written to `~/.config/cava/colors`.

## firefox/

Firefox browser configuration.

### default.nix
Home Manager `programs.firefox` module:
- Declares a single profile named `default` (id 0, isDefault true) — creates `~/.mozilla/firefox/default/`
- Enables `toolkit.legacyUserProfileCustomizations.stylesheets` for userChrome support
- Installs extensions: Proton Pass, Proton VPN, uBlock Origin
- Symlinks `userChrome.css` from `/etc/nixos/config/programs/firefox/chrome/` (out-of-store, editable live)
- Writes `userContent.css` statically (imports matugen-generated GitHub and YouTube theme files)

### chrome/userChrome.css
Firefox UI theme. Overrides tab colors, toolbar, and address bar using matugen CSS variables (populated at runtime). Rounds tab corners, removes unnecessary chrome elements.

### chrome/userContent.css
Imports two matugen-generated files:
- `~/.mozilla/firefox/default/chrome/matugen-github.css`
- `~/.mozilla/firefox/default/chrome/matugen-youtube.css`

These files are generated by matugen when the wallpaper changes and are not tracked in the repo.

## kitty/

Kitty terminal emulator.

### default.nix
Symlinks the entire `~/.config/kitty/` directory to `/etc/nixos/config/programs/kitty/` (out-of-store). This means `kitty.conf` can be edited live.

### kitty.conf
Static terminal configuration:
- Font: `MesloLGS NF` 12pt (supports Powerline/Nerd Font glyphs for zsh prompt)
- Background: `#1a1b26` at 35% opacity
- Disabled window decorations, 4px padding, 2000 scrollback lines
- `include /tmp/kitty-matugen-colors.conf` — injects dynamic color palette generated by matugen at wallpaper change

## matugen/

Material You color generator. Generates synchronized color schemes for all supported apps from a single wallpaper image.

### default.nix
Symlinks `~/.config/matugen/` → `/etc/nixos/config/programs/matugen/` (out-of-store).

### config.toml
Defines 8 template pipelines. Each entry maps an input template to an output path:

| Template key | Output |
|---|---|
| `quickshell` | `/tmp/qs_colors.json` |
| `kitty` | `/tmp/kitty-matugen-colors.conf` |
| `firefox` | `~/.mozilla/firefox/default/chrome/matugen.css` |
| `web_github` | `~/.mozilla/firefox/default/chrome/matugen-github.css` |
| `web_youtube` | `~/.mozilla/firefox/default/chrome/matugen-youtube.css` |
| `neovim` | `~/.config/nvim/matugen_colors.lua` |
| `cava` | `~/.config/cava/colors` |
| `swayosd` | `~/.config/swayosd/style.css` |
| `swaync` | `~/.config/swaync/style.css` |
| `rofi` | `~/.config/rofi/theme.rasi` |

### templates/
Input templates for each pipeline. They contain CSS / Lua / INI / JSON with `{{colors.<name>}}` placeholders that matugen substitutes with hex values derived from the wallpaper.

| File | Target app |
|---|---|
| `firefox.css` | Firefox base styles |
| `kitty-colors.conf.template` | Kitty 16-color terminal palette |
| `nvim-colors.lua.template` | Neovim highlight groups |
| `cava-colors.ini.template` | CAVA bar colors |
| `rofi.rasi.template` | Rofi launcher theme |
| `swaync.css.template` | Swaync notification center |
| `swayosd.css.template` | SwayOSD (volume/brightness overlay) |
| `websites/github.css.template` | GitHub website theme |
| `websites/youtube.css.template` | YouTube website theme |

## neovim/

Neovim text editor.

### default.nix
Configures Neovim via Home Manager `programs.neovim`:
- ~20 plugins: Catppuccin theme, Treesitter, LSP (lua-ls, pyright, nil), nvim-cmp, Telescope, nvim-tree, lualine, gitsigns, Comment.nvim, etc.
- Formatters: stylua, black, nixfmt
- Symlinks `init.lua` from `/etc/nixos/config/programs/neovim/nvim/` (out-of-store)

## plymouth/

Boot animation.

### default.nix
Empty module. Plymouth is configured directly in `configuration.nix` (boot.plymouth block) because it requires a system-level derivation to package the custom theme.

The theme source lives at `config/programs/plymouth/simple/`.

## rofi/

Application launcher.

### default.nix
Symlinks `~/.config/rofi/config.rasi` from `/etc/nixos/config/programs/rofi/config.rasi` (out-of-store).

### config.rasi
Rofi configuration:
- Modes: `drun` (app launcher), `filebrowser`, `window` (window switcher)
- Shows application icons
- Imports `theme.rasi` — generated at runtime by matugen into `~/.config/rofi/theme.rasi`

On-screen display for volume and brightness changes.

Enables the `services.swayosd` Home Manager service with:

- Symlinks the CSS stylesheet from `~/.config/swayosd/style.css` (written by matugen)

## zsh/

Zsh shell.

### default.nix
Home Manager `programs.zsh` module:
- Enables completion, autosuggestion, syntax highlighting
- History: 10 000 entries, deduplication, stored at `~/.zsh_history`
- oh-my-zsh with `git` plugin and `robbyrussell` theme
- Shell aliases: `edit` (sudo nvim), `gitavail` (load GitHub SSH key), `update` (nixos-rebuild), `stop` (shutdown), `out` (logout current user)
- Session variables: `$hypr` → Hyprland config dir, `$programs` → programs config dir
- Sources `zsh-init.sh` for custom functions

### zsh-init.sh
Custom shell functions loaded at every Zsh startup:
- `cd` — overrides built-in `cd` to run `ls` after every directory change
- `qcopy` — interactive fzf file picker that copies file contents to clipboard (useful for pasting into LLMs)
- `fetch` — runs `fastfetch` with a Catppuccin color palette built from matugen colors
- `pasteimg` — pastes an image from the clipboard using `wl-paste`
- `stsetup` — project-specific dev environment setup (Stewart project)
